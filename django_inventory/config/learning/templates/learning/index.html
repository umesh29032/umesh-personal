How this works (and why it can never go stale)

These pages render the markdown files in docs/ directly. There is no second copy of the content, so the courses and the engineering docs can never drift apart. Edit a .md file and this site changes with it. Every chapter link is a normal URL — Ctrl+click (or long-press) to open chapters in their own tabs.
