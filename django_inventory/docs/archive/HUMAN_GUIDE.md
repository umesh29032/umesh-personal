# 🧭 Human Guide — docs/archive/ — superseded history

> Museum guide, not an exhibit: navigation only, no content lives here.
> The full map of docs/: [kos/project/reading-the-docs.md](../../kos/project/reading-the-docs.md)

**Why does this folder exist?**
Where superseded and dated documents retire. Nothing here is current truth.

**What kinds of documents live here?**
Old audits, superseded designs, shipped plans, era reviews.

**Read first:**
Nothing, unless doing historical forensics ('what did we believe in May?').

**Usually ignorable:**
All of it, for daily work — that's the point of an archive.

**Which KOS pages explain these documents?**
[reading-the-docs](../../kos/project/reading-the-docs.md); if an archived doc seems load-bearing, its live successor is named in its banner.

**Engineering topics that belong here:** history only
